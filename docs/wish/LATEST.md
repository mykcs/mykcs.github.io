# 当前愿望

更新：2026-09-23

> **我希望 mykcs.github.io 永远是一个稳定、轻量的旧主页入口：已经传播出去的链接继续有效，并直接把访问者送到当前正式主页；它自己不复制完整网站，也不要求私人开发源码变成公开。**

优先保护三件事：

- **旧链接长期有效。** 换托管商时优先改这里的目标，而不是让旧网址失效。
- **只有一个正式主页。** 本仓库不是第二份内容站，canonical 内容只在正式 serving host。
- **公开入口与私人开发分离。** 这里保持 Public 且最小；完整源码和开发历史继续保持 Private。

这个仓库不应该长成完整主页，也不应该成为 private source 的公开镜像。
